# Push-Up 30 — widget Android

Projeto Android simples de widget para acompanhar 30 dias. O widget guarda o progresso localmente no aparelho.

## Como instalar
1. Abra esta pasta no Android Studio (File > Open).
2. Aguarde a sincronização do Gradle.
3. Use Build > Build Bundle(s) / APK(s) > Build APK(s).
4. Instale o APK gerado.
5. Na tela inicial do Android, pressione e segure um espaço vazio > Widgets > Push-Up 30.
6. Arraste o widget para a tela inicial.

## Uso
- **CONCLUIR DIA** avança um dia no desafio.
- **REINICIAR** zera o contador.

O contador registra dias, não verifica se o exercício foi realmente feito. Os dados ficam no armazenamento local do app.

## Plano incluído
Sessões nos dias 1, 3, 5; 8, 10, 12; 15, 17, 19; 22, 24, 26. Volume por sessão: 30, 40, 50 e 60 flexões por semana, respectivamente. Dias 29 e 30 são recuperação.
